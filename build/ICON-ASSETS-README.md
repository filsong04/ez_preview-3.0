# EZ Preview app icon assets

All deployment icon formats below use the supplied black-background, yellow EZ logo.

- `icon.icns`: macOS app and DMG icon, containing sizes from 16px through 1024px.
- `icon.ico`: Windows icon with 16px, 24px, 32px, 48px, 64px, 128px, and 256px entries.
- `icon.png`: 1024×1024 master icon for Linux and preview use.
- `icon.svg`: self-contained SVG wrapper that embeds the 1024×1024 PNG artwork.
- `ez-logo-original.png`: original user-supplied image preserved unchanged.

The app icon has been framed to keep the horizontal EZ mark readable within square operating-system icon slots. The underlying yellow artwork is retained; only cropping/fit and the near-black background normalization were applied to generated assets.
